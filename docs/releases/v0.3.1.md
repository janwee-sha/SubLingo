# SubLingo v0.3.1

## 新功能

- 选择外挂或内嵌文本字幕后，SubLingo 会自动识别主要字幕语言，不再要求用户填写或确认字幕语言。
- `Languages` 区域改用 `Target Language`，提供更完整的目标语言选项，并保留中文简体、中文繁体、葡萄牙语和葡萄牙语（葡萄牙）等语言变体的区别。

## 功能改进

- 点击 `Save Languages` 后，目标语言会立即用于当前翻译，并在关闭 Sidebar、完整退出或重启 IINA 后恢复最近一次成功保存的选择；没有有效保存值时默认使用中文（简体）。
- 当字幕语言无法可靠识别或不受支持时，SubLingo 不会发送字幕内容或生成错误方向的译文，原视频和原字幕仍可正常播放，并显示相应状态。
