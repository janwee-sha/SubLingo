# SubLingo v0.3.4

## 新功能

- OpenAI-compatible 与 Ollama 均可使用完整的本地或远程 HTTP(S) endpoint 保存、测试、选择并翻译字幕。

## 功能改进

- 操作进度和结果会显示在对应控件下方，界面仅保留最新一条消息，直到下一项操作反馈替换它。
- 新建 Profile 默认使用当前 Service type 名称；手动输入和既有名称不会在切换类型时被覆盖。
- Profile 更新和连接测试后的翻译选择提示更加简洁一致。

## 问题修复

- Profile 删除成功后会立即从当前列表消失，并防止迟到的列表刷新重新显示已删除条目。
