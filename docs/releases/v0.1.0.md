# SubLingo v0.1.0

## 新功能

- 在 IINA 播放带有外挂 SRT 或 ASS 字幕的视频时，保留原字幕作为主字幕，并将当前位置附近的译文显示为第二字幕；翻译延迟或失败不会暂停视频或隐藏原字幕。
- 支持设置母语并确认字幕源语言；源语言与母语相同时不会发送翻译请求，无法确认源语言时会先等待用户选择。
- 支持创建、测试、选择、编辑和删除 OpenAI-compatible 与 Ollama 翻译服务 Profile，并可为每个 Profile 选择使用 macOS 系统代理或直接连接。
- 只向用户明确选择的服务发送当前位置附近所需的字幕文本。OpenAI-compatible 凭据保存在插件专用的本地文件中，保存后不再回显；Ollama Profile 不保存凭据。
- 成功译文会在当前视频会话内复用，跳回已翻译片段时无需重复请求；换片、禁用翻译或关闭窗口后会清理所属会话数据。
- 支持多个 IINA 窗口同时翻译，各窗口的服务选择、缓存、状态和第二字幕互不影响。

## 升级与兼容提醒

- 本版本支持 macOS 12 或更高版本及 IINA 1.4.0 或更高版本。
- 本版本仅翻译用户在 IINA 中手动加载并选择的外挂 SRT 或 ASS 文本字幕；不支持内嵌字幕、图形字幕、画面字幕或音频转写。
- 使用前需要自行准备受支持的翻译服务和模型。译文仅在当前视频会话内缓存，不提供整片预翻译、持久缓存、编辑或导出。
