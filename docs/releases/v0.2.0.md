# SubLingo v0.2.0

## 新功能

- 支持直接翻译 IINA 当前选中的本地内嵌文本字幕，包括 Matroska 中的 SubRip、ASS、SSA，以及 MOV/MP4 中的 `mov_text`；无需手动导出字幕或安装额外工具。
- 内嵌字幕沿用双语观看体验：原字幕保持为主字幕，当前位置附近的译文显示在第二字幕轨。

## 功能改进

- 切换字幕、媒体或播放器窗口时，SubLingo 会以当前选择为准，避免旧字幕的准备或翻译结果进入新会话；切回外挂字幕无需重启播放或插件。
- 字幕准备不会暂停视频或隐藏原字幕，并会区分准备中、不支持、远程媒体不支持、字幕不可读、超时和失败等状态；失败后可手动重试或重新选择字幕。

## 升级与兼容提醒

- 内嵌字幕翻译首版仅支持本地媒体。PGS、VobSub、DVB 等图形字幕、画面硬字幕、音频转写和远程媒体内嵌字幕暂不支持。
- 正式包支持 macOS 12 或更高版本、IINA 1.4.0 或更高版本，以及 Apple Silicon 和 Intel Mac。
