# SubLingo v0.3.5

## 新功能

- OpenAI 与 Ollama 的 Model ID 现在可直接展示当前 Endpoint 返回的模型，支持刷新后选择，也可继续输入自定义 Model ID。
- Ollama Profile 现在支持可选 API Key，可用于需要认证的远程服务，并统一作用于模型刷新、连接测试和字幕翻译。

## 功能改进

- 服务类型的可见名称由 OpenAI-compatible 简化为 OpenAI，仍可使用兼容 OpenAI API 的自定义 HTTP(S) Endpoint。
- 启动 IINA、打开 SubLingo 或更改 Endpoint 时会自动更新模型列表；也可使用 Model ID 旁的刷新按钮立即更新。
- 已保存的 API Key 继续保持只写；重新编辑 Profile 时只显示已配置状态，不会回显凭据。

## 升级与兼容提醒

- 既有 OpenAI Profile 的名称、Endpoint、Model ID 和凭据状态保持不变，仅服务类型标签更新为 OpenAI。
- 模型列表刷新可能在选择 Profile 前访问已配置或正在编辑的 Endpoint，但不会发送字幕；字幕翻译仍需先明确选择 Profile。
