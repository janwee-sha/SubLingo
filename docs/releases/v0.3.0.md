# SubLingo v0.3.0

## 功能改进

- 译文改由 SubLingo 在播放窗口顶部中央自行渲染，不再新增、切换或移除字幕轨；原字幕与用户已有的第二字幕选择保持不变，翻译更新时不再出现由 SubLingo 引起的轨道切换通知。
- 译文默认使用白色、透明背景和清晰描边，并以 720p 高度下的字号 40 为基准随窗口等比缩放；多行与长文本会按可用宽度自动换行。
- 暂停时会保留当前有效译文；跳转、换轨、换片、禁用翻译或关闭窗口后会及时清除过期内容，多个播放窗口的译文互不影响。

## 升级与兼容提醒

- 本版本仅提供固定默认样式，不支持自定义字体、颜色、字号、背景或位置，也不支持拖动译文。
- 极窄窗口或超长译文仍保持固定缩放规则，超出窗口高度的内容可能被裁切。
