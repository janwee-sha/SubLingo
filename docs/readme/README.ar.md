يترجم SubLingo ملف الترجمة النصية الخارجي SRT أو ASS المحدد حاليًا في [IINA](https://iina.io/)، ويعرض النتيجة كمسار ترجمة نصية ثانٍ. لا يعالج إلا نطاقًا قصيرًا أمام موضع التشغيل، ويترجم على دفعات محدودة. يستمر تشغيل الفيديو والترجمة الأصلية حتى إذا تأخرت الترجمة أو فشلت.

## ✨ الميزات

- **ترجمة نصية ثنائية اللغة وفورية:** تبقى الترجمة الأصلية هي المسار الأساسي، وتظهر الترجمة الجديدة كمسار ثانٍ في IINA.
- **دعم ملفات SRT وASS الخارجية:** يعمل مع مسارات SRT وASS/SSA النصية الخارجية القابلة للقراءة والمحددة في IINA.
- **اختيار خدمة الترجمة:** استخدم endpoint متوافقًا مع OpenAI Chat Completions أو خادم Ollama محليًا أو بعيدًا.
- **أولوية التشغيل:** لا توقف عملية الترجمة الفيديو ولا تخفي الترجمة الأصلية.
- **طلبات محدودة:** يترجم SubLingo مقاطع cue القريبة فقط، ويحد من العمل المتزامن لكل نافذة تشغيل، ويخزن النتائج الناجحة مؤقتًا لجلسة الفيديو الحالية فقط.
- **عدة Profile:** احفظ Profile لخدمات الترجمة واختبرها، ثم حدد بوضوح endpoint الدقيق المسموح له باستقبال نص الترجمة.
- **التحكم في الوكيل:** استخدم إعدادات proxy في macOS أو اختر اتصالًا مباشرًا لكل Profile.

## ✅ المتطلبات

- macOS 12 أو أحدث
- IINA 1.4.0 أو أحدث
- مسار ترجمة نصية خارجي SRT أو ASS/SSA قابل للقراءة
- إحدى خدمات الترجمة التالية:
  - endpoint متوافق مع OpenAI وModel ID وAPI key إذا كانت الخدمة تتطلبه
  - خادم Ollama مثبّت عليه مسبقًا نموذج متوافق

لا يقوم SubLingo بتنزيل نماذج الترجمة أو تشغيلها.

## 🚀 التثبيت

افتح IINA وانتقل إلى **Settings → Plugins**. تدعم واجهة إدارة الإضافات طريقتي التثبيت التاليتين.

![واجهة إدارة إضافات IINA وبها زرا التثبيت من GitHub وتثبيت الحزمة](assets/plugin-manager.webp)

### التثبيت من GitHub (موصى به)

1. انقر **Install from GitHub…**.
2. أدخل `janwee-sha/SubLingo` في حقل `user/repo`، ثم أكد التثبيت.
3. انتظر حتى يظهر SubLingo في قائمة الإضافات المثبتة.

يستطيع IINA تحديث الإضافات المثبتة من GitHub تلقائيًا.

### تثبيت حزمة تم تنزيلها

1. افتح صفحة [Releases](https://github.com/janwee-sha/SubLingo/releases) ونزّل أحدث حزمة `SubLingo-X.Y.Z.iinaplgz`.
2. ارجع إلى **Settings → Plugins** وانقر **Install Package…**.
3. اختر ملف `.iinaplgz` الذي نزّلته وأكد التثبيت.

في كلتا الطريقتين، وافق على أذونات الإضافة المطلوبة إذا ظهرت، وتأكد من تفعيل مربع الاختيار بجوار SubLingo، ثم أعد تشغيل IINA. بعد ذلك شغّل فيديو، وافتح الشريط الجانبي في IINA، واختر تبويب **SubLingo**.

## 🌍 البدء السريع

1. افتح فيديو وحدد ملف SRT أو ASS خارجيًا بوصفه الترجمة النصية الأساسية.
2. ضمن **Languages**، اختر لغتك الأم. إذا تعذر على IINA تحديد لغة الترجمة، فأكدها يدويًا ثم احفظ إعدادات اللغة.
3. ضمن **Translation service**، أنشئ Profile من نوع OpenAI-compatible أو Ollama وأدخل Model ID الدقيق.
4. احفظ Profile واختبره، ثم انقر **Select**. يعني تحديد Profile أنك تمنح SubLingo إذنًا صريحًا لإرسال نص الترجمة القريب إلى endpoint المعروض.
5. فعّل **Translate**. تبقى الترجمة الأصلية أساسية، وتظهر مقاطع cue المترجمة كمسار ثانٍ.

إذا تغير endpoint أو النموذج أو API key أو مسار الشبكة، فاحفظ Profile المحدّث وحدده مرة أخرى قبل الترجمة.

## ⚙️ خدمات الترجمة

### OpenAI-compatible

- أدخل API root مثل `https://example.com/v1`، وليس عنوان `/chat/completions` كاملًا.
- يضيف SubLingo المسار `/chat/completions` ويعرض عنوان الطلب النهائي في الشريط الجانبي.
- أدخل المعرّف الدقيق للنموذج الذي توفره خدمتك.
- يكون Bearer API key اختياريًا فقط إذا كان endpoint يقبل الطلبات من دون مصادقة. يصبح الحقل مخصصًا للكتابة فقط بعد الحفظ، ولا تظهر القيمة المحفوظة مجددًا.
- يجب أن تستخدم endpoint البعيدة HTTPS.

### Ollama

- عنوان الخادم الافتراضي هو `http://127.0.0.1:11434`.
- أدخل tag الدقيق للنموذج المثبت، مثل `translategemma:12b` أو `qwen3:14b`.
- لا تحفظ Profile الخاصة بـOllama بيانات اعتماد API ولا تستخدمها.
- يتحقق اختبار الاتصال من الخادم وtag المثبتة ودعم structured-output chat.

ابدأ مع أي من الخدمتين بخيار **Use macOS proxy settings**. اختر **Connect directly** فقط عندما يمنع proxy النظام المضبوط الوصول إلى الخدمة.

## 🔒 الخصوصية وبيانات الاعتماد والتكلفة

- لا يرسل SubLingo إلا نص cue القريب واتجاه اللغة ومعرّفات cue غير الدلالية وقدرًا محدودًا من السياق المجاور إلى Profile الذي حددته صراحة. ولا يرسل محتوى الفيديو أو الصوت.
- تُحفظ OpenAI-compatible API key محليًا كنص واضح في ملف الإضافة الخاص `credentials.json`. يستخدم المجلد صلاحية `0700` والملف صلاحية `0600`. لا تُكتب key في IINA preferences أو السجلات أو التشخيص أو حالة Sidebar أو حزمة الإضافة، ولا تُعرض مرة أخرى بعد الحفظ.
- تحمي صلاحيات الملف key من حسابات macOS الأخرى ومن الوصول العرضي المعتاد، لكنها لا تحميها من عملية تستطيع أصلًا قراءة الملفات بصلاحيات مستخدم macOS الحالي.
- يستمع transport helper المرفق إلى منفذ مؤقت على `127.0.0.1` فقط، ويرسل الطلبات البعيدة إلى endpoint المحدد فقط. تُرفض عمليات redirect بين المصادر وبيانات الاعتماد المضمّنة في URL.
- تُخزن الترجمات مؤقتًا لجلسة الفيديو الحالية فقط، وتُمسح عند تغيير الفيديو أو انتهاء التشغيل أو إغلاق النافذة.
- قد تفرض خدمة الترجمة رسومًا على الطلبات وتطبق سياساتها الخاصة بالبيانات والمحتوى. يقلل التجميع والتخزين المؤقت عدد الاتصالات، لكنهما لا يضمنان حدًا أقصى للتكلفة.

## 📌 النطاق الحالي

لا يوفر SubLingo نسخ الصوت، أو OCR/استخراج الترجمة الرسومية أو المضمّنة، أو الترجمة المسبقة للفيديو كاملًا، أو تصدير الترجمة، أو المزامنة السحابية، أو التخزين الدائم للترجمات.

## 🛠️ استكشاف الأخطاء

- **Select a readable external SRT or ASS subtitle:** حدد ترجمة نصية خارجية بوصفها المسار الأساسي في IINA. لا تُدعم المسارات الرسومية أو المضمّنة.
- **Confirm the subtitle language:** أدخل tag لغة BCP 47 مثل `en-US` ثم احفظ إعدادات اللغة.
- **Translation service unavailable:** اختبر Profile وتحقق من endpoint والنموذج وAPI key ومسار الشبكة أو عملية Ollama. يستمر تشغيل الفيديو والترجمة الأصلية بصورة طبيعية.
- **Credential could not be saved:** ثبّت حزمة Release بدلًا من نسخة تطوير ناقصة، وتأكد من إمكانية الكتابة في مجلد بيانات الإضافة، ثم أغلق IINA بالكامل وأعد تشغيله.
- **لا يظهر مسار الترجمة الثاني:** تأكد من اختبار Profile وتحديده، ومن اختلاف لغة المصدر عن لغتك الأم، ومن تفعيل **Translate**. تأكد أيضًا من أن IINA لم يغيّر المسار الثاني يدويًا بعد أن حمّله SubLingo.
- **يحجب proxy الخدمة:** جرّب أولًا مسار proxy الافتراضي في macOS. إذا رفض الخدمة، فغيّر Profile إلى **Connect directly** واحفظه ثم نفّذ Select/Test مجددًا.
