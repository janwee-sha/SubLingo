# 数据模型：IINA 自动更新发现

## 更新身份

| 字段 | 规则 |
| --- | --- |
| 用户版本 | 稳定 `major.minor.patch`，每个分量为 0–999 |
| 更新仓库 | 固定为 `janwee-sha/SubLingo` |
| 更新序号 | `major × 1,000,000 + minor × 1,000 + patch` |

更新身份由三个字段共同确定。0.3.3 的唯一合法更新序号是 `3003`。

## 正式安装包

- 包内 `Info.json` 必须保留与源码相同的更新身份。
- 包名、包内用户版本和发布目标版本必须一致。
- 更新身份校验通过后，现有权限、文件白名单和 native helper 校验继续执行。

## 旧版安装

| 状态 | 可发现后续更新 | 转换方式 |
| --- | --- | --- |
| 0.3.2 及更早 | 否 | 手动安装 0.3.3 |
| 0.3.3 | 是 | IINA 更新检查 |
| 高于 0.3.3 | 是 | IINA 更新检查，前提是发布身份继续满足契约 |

## 状态转换

```text
旧版安装 --一次手动升级--> 0.3.3 可更新安装 --IINA 更新检查--> 后续可更新安装
```

无回退迁移、后台状态或持久化数据变化。
