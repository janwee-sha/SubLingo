# v0.1.0 一次性替换合同

## 输入

- 当前审计后的 v0.1.0 安装包、校验文件与发布正文。
- 当前触发 commit。
- 固定旧 tag commit 和旧安装包 SHA-256。
- 显式一次性替换开关，仅允许 `v0.1.0`。

## 前置条件

- 恰好一个公开、非 prerelease 的 `v0.1.0` Release。
- tag 指向固定旧 commit。
- 远程安装包下载哈希等于固定旧 SHA-256。
- 旧 Release 资产结构无冲突。
- 旧正文和全部旧资产已下载到本次进程的临时目录并完成哈希核验。

任一条件不满足时不得删除或覆盖远程对象。

## 输出

- `v0.1.0` tag 指向当前触发 commit。
- Release 公开、非 prerelease、Latest，正文等于当前审计正文。
- 安装包和 `.sha256` 资产内容与本次审计一致。
- 一次性模式在后续清理提交中移除；普通发布仍对已发布稳定版本返回 `skipped`。

删除旧远程对象后的任一步骤失败时，流程必须删除未完成的新对象，并使用缓存的旧正文、全部旧资产和旧 commit 重建公开稳定 Latest v0.1.0；恢复核验成功后仍以失败状态结束本次 Actions。
